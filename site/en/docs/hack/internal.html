EcoCONNECT technical notes ​

Structure and specifications ​

EcoCONNECT is made of a main board and a STEAM board. It runs on three alkaline batteries or USB power, and it is an IoT device with several connector wires you can use freely.

Main board ​

Overview ​

The main board processes data from each sensor device and sends that data. It is a four-layer board. The MPU is a Raspberry Pi Pico 2, connected to the LoRaWAN module (A660-900T22) by serial communication. It also talks to the sensors on the STEAM board over an I2C bus.

The LoRaWAN module (A660-900T22) can be fitted either as the module alone or as the evaluation module. To check LoRaWAN behavior, mount the evaluation module on pin headers. Debugging is smoother that way.

Pin assignment ​

Role and pin assignment of each connector. When you use the STEAM board, connectors J1 and J2 are used. Pins on the expansion connectors (J4 and J6) are free to use. The firmware-update connector (J7) is used when updating the LoRaWAN module firmware. Pins on the add-on board connectors (J5 and J8) are reserved for future expansion.

STEAM board ​

Overview ​

This is a four-layer board with environmental sensors (temperature, humidity, ambient light, and pressure). Each sensor talks to the MPU on one I2C bus.

The sensors expected on the board are the BME280 (temperature, humidity, and pressure) and the BH1750 (illuminance). Mount the BME280 on the front of the board and the BH1750 on the back.

Add pull-up resistors (R1 and R2) when the sensor module you use does not already include them.
