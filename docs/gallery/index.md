# ギャラリー

コミュニティの作品、教室の写真、やさしいショー＆テルの場所です。

## 共有してほしいもの

- セットアップの写真（顔は不要）
- 短いキャプション：何を測り、何がわかったか
- 任意：データのスケッチやポスター

## 投稿のしかた

1. 画像とキャプションを添えて、GitHub の Discussion または Pull Request を開く
2. ファイルは小さめ・わかりやすい名前に
3. 児童・クラブのクレジットは、本人の希望どおりに
