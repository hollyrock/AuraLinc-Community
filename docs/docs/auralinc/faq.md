## ボード・書き込み

### 書き込み用のドライブが見つかりません

BOOTSEL を押しながら USB をさし直してください。Raspberry Pi Pico では、多くの場合 `RPI-RP2` という名前のドライブが表示されます。

### どのファイルをコピーすればよいですか？

`firmware/pico2/release/ecoconnect-pico2.uf2` を使います。手順は [はじめ方](../hack/getting-started) と `firmware/pico2/README.md` を参照してください。

### 書き込み後に何も起きません

ケーブルを抜け差しし、電源ランプの有無を確認してください。それでもだめなら [コミュニティ広場](/community/) に状況（OS・ケーブル・表示されたドライブ名）を書いてください。
