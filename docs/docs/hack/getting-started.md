# さあ！始めよう！

ようこそ！
このページでは、約 15〜20 分で **EcoCONNECTを使ってセンサーデータを読み取る** まで進めます。

## 用意するもの

- EcoCONNECT メインボード（完成品）
- Micro-USB ケーブル
- パソコン（Windows / macOS / Linux）

## 手順

### 1. EcoCONNECTメインボードをPCに接続する

Micro USBケーブルでEcoCONNECTメインボードとPCを接続します。接続すると電源LEDが一瞬点滅します。
[EcoCONNECTのコネクターの位置](#)

### 2. 用意済みファームウェアを書き込む

EcoCONNECT には、コードを書かなくても使える **書き込み用イメージ** があります。

1. リポジトリの `firmware/pico2/release/` を開く
2. `firmware/pico2/` の README に従い、`.uf2` を Raspberry Pi Pico にコピーする
3. ボードが再起動したら、最初の計測の準備完了です

::: tip
書き込み時にはUSBケーブルを抜いたりしないでください。
:::

### 3. センサーの値を読み取る

ターミナルを開いて、センサー読み取りプログラムを実行します。

### 4. 高度な使い方

ここまででセンサーの値をPCで利用することができました！
次のステップ[データを無線で送信する](/docs/hack/remote)に進みましょう。
