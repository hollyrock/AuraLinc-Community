# AuraLinc EcoCONNECT とは？

EcoCONNECT は、環境モニタリングシステム（AuraLinc）で利用可能な**オープンソースのIoTデバイス**です。

改造はもちろん、自作センサーの取り付けや環境モニタ以外の機能を追加するといった、「ハック」ができるデバイスです。

学校や地域のワークショップを始め、農業の現場での環境モニタリング、ITエンジニアリングに挑戦するクラブやメイカースペースなどで利用いただけたら幸いです。

## ブラックボックスを、解き放とう

仕組みが見える。好きに拡張できる。仲間と一緒にアップデートできる。

ソフトウェア（OSS）のコードから、ハードウェア（OSHWA）の設計図まで、その「中身」をオープンにしています。

**仕組みが見える：**

ブラックボックスはありません。どう動き、どう作られているかを自分の目で確かめられます。

**好きに拡張できる：**

欲しい機能をコードで足すのも、3Dプリンタで新しいパーツを作るのも、すべてあなたの自由です。

**仲間と一緒にアップデートできる：**

自分が作った改良やアイデアをコミュニティにシェアすると、世界中の誰かの課題を解決する力になります。課題にぶつかっても、コミュニティの仲間と考え、解決策を探ることができます。

## コミュニティでできること（開発者じゃなくても大歓迎です！）

あなたのアイデアが、世界を少し動かす。

使うだけじゃ、もったいない。

* **使ってみた感想や写真をシェアする**（最高のフィードバックです）

* **「こんな使い方できたよ」と報告する**（新しい可能性の発見になります）

* **ここが分かりにくかった」と伝える**（マニュアルやデザインの改善につながります）

* **もちろん、コードを書く・ハードを改良する**（大歓迎のアップデートです）

一人のアイデアが世界中に届き、世界中の工夫があなたの元に届く。

コードを1行書くことだけが参加ではありません。

「ここを変えたら便利だった」「こんな使い方を見つけた」

——その報告ひとつが、世界中のユーザーを助ける大きな貢献になります。

技術を自分の手に取り戻し、世界とつながるコミュニティへ、ようこそ！
