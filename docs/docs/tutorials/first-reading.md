# はじめてのセンサー計測

**目標：** EcoCONNECT ボードからリアルタイムの値を見て、かんたんな言葉で意味を説明する。

**時間：** 約 10 分  
**レベル：** 初心者

## はじめる前に

[はじめ方](/docs/getting-started) を終わらせ、ファームウェアを書き込んでおいてください。

## 手順

1. 清潔で乾いた机の上にボードを置く
2. USB で電源をつなぐ
3. キットの説明で初心者向けとされているツール／シリアルモニタを開く
4. センサーにさわらず、30 秒ほど数値を見る
5. 環境をそっと変える（例：光センサーを手で覆う、温度センサーを手であたためる — キットが安全と書いている場合のみ）
6. 数値がどう変わるか観察する

## ノートに書くこと

- 変わらなかったことは？
- 変わったことは？
- なぜ変わったと思う？

## できた！の目安

計測を一文で説明できたら OK です。例：

> 「センサーを覆ったら、光の値が下がった。」
