# メーカー向け

このページは任意です。初心者の方は [はじめ方](/guide/getting-started) と [チュートリアル](/tutorials/) だけで大丈夫です。

## このリポジトリで公開しているもの

| フォルダ | 内容 |
| --- | --- |
| `docs/` | 初心者向けドキュメント |
| `firmware/pico2/release/` | 書き込み用ファームウェア画像 |
| `hardware/main-board/` | メインボード設計ファイル（OSHWA 向けオープンハードウェア） |

## メーカー向けのすすめ方

1. `firmware/pico2/README.md` で書き込み手順を読む
2. `firmware/pico2/release/` のイメージを使う
3. 設計を見たくなったら `hardware/main-board/` を KiCad で開く

内部のビルド用ツールやアプリのソースは、この公開コミュニティリポジトリには入れていません。新しく来る人が迷わないためです。
