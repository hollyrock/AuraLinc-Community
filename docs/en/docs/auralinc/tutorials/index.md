# Tutorials

Short guided activities. Start at the top and move down when you feel ready.

## Path for beginners

1. [Getting started](/en/docs/hack/getting-started) — power on and flash
2. [Your first EcoCONNECT](/en/docs/auralinc/tutorials/first-reading) — watch a real measurement
3. Pick a [recipe](/en/steam/recipes) — try a small experiment

## Tips

- Read one step at a time
- If a step fails, go back one step
- Write down what you see — good observation starts with notes
