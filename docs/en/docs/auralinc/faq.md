# FAQ

Common questions. If yours is not listed, ask in the [Community plaza](/en/community/).

## Board and flashing

### I cannot find the drive for flashing

Hold BOOTSEL and plug the USB cable in again. On Raspberry Pi Pico, the drive is often named `RPI-RP2`.

### Which file should I copy?

Use `firmware/pico2/release/ecoconnect-pico2.uf2`. See [Getting started](../hack/getting-started) and `firmware/pico2/README.md`.

### Nothing happens after flashing

Unplug and replug the cable, and check whether a power LED is on. If it still fails, post in the [Community plaza](/en/community/) with your OS, cable, and the drive name you saw.
