# Tutorials

Short, guided activities. Start at the top and move down when you feel ready.

## Path for beginners

1. [Getting started](/en/docs/getting-started) — power on and flash the board
2. [Your first sensor reading](/en/docs/tutorials/first-reading) — observe a real measurement
3. Pick a [recipe](/en/steam/recipes) — try a tiny experiment

## Tips for success

- Read one step at a time
- If a step fails, go back one step before troubleshooting further
- Write down what you see — good science starts with notes
