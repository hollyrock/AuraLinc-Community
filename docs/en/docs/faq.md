# FAQ

Common questions. If yours isn’t listed, ask in the [Community plaza](/en/community/).

## Board and flashing

### I can’t see the USB drive for flashing

Hold BOOTSEL while plugging in USB. On Raspberry Pi Pico the drive is often named `RPI-RP2`.

### Which file should I copy?

Use `firmware/pico2/release/ecoconnect-pico2.uf2`. See [Getting started](./getting-started) and `firmware/pico2/README.md`.

### Nothing happens after flashing

Unplug and replug USB, check for a power LED. If it still fails, post in the [Community plaza](/en/community/) with your OS, cable, and drive name.
