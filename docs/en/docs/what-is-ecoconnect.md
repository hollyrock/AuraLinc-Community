# What is AuraLinc EcoCONNECT?

EcoCONNECT is an **open-source IoT device** that works with AuraLinc, an environmental monitoring system.

You can modify it, attach your own sensors, and add functions beyond environmental monitoring. It is a device you can **hack**.

We hope it is useful in school and community workshops, environmental monitoring in agriculture, and in clubs and makerspaces where people try IT engineering.

## Open the black box

You can see how it works. You can extend it as you like. You can update it together with others.

From software (OSS) source code to hardware (OSHWA) design files, the “inside” is open.

**You can see how it works:**

There is no black box. You can check with your own eyes how it runs and how it is built.

**You can extend it as you like:**

Add a feature in code, or make a new part on a 3D printer. That choice is yours.

**You can update it with others:**

When you share an improvement or an idea with the community, it can help someone else’s problem. When you get stuck, you can think it through with the community and look for a solution.

## What you can do in the community (you do not have to be a developer)

Your idea can move the world a little.

Just using it is only the start.

* **Share what you tried, and photos** (the best kind of feedback)

* **Report “I used it this way”** (that can reveal a new possibility)

* **Say “this part was hard to understand”** (that improves the manual and the design)

* **Of course, write code or improve the hardware** (updates are very welcome)

One person’s idea reaches people everywhere, and ideas from everywhere come back to you.

Writing a line of code is not the only way to take part.

“This change made it easier.” “I found this way to use it.”

— One report like that can be a real help to users everywhere.

Welcome to a community where you take technology into your own hands and connect with the world.
