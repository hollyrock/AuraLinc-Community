# For makers

This page is optional. Beginners can stay in the [guides](/en/guide/getting-started) and [tutorials](/en/tutorials/).

## What’s shared publicly in this repository

| Folder | Contents |
| --- | --- |
| `docs/` | Beginner-friendly documentation |
| `firmware/pico2/release/` | Ready-to-flash firmware images |
| `hardware/main-board/` | Open main-board design files (OSHWA-oriented) |

## Suggested path

1. Read `firmware/pico2/README.md` for flash steps
2. Use the image in `firmware/pico2/release/`
3. Open `hardware/main-board/` in KiCad when you want to explore the board design

Internal build tooling and application source stay out of this public community repository so newcomers are not overwhelmed.
